# CoursePilot 项目现状与后续任务

更新日期：2026-11-23。

## 项目目标

将培养要求、课程信息、兴趣与时间约束汇总为可解释的课表预案，并支持选课期间的备选调整；后续通过学习反馈改善课程画像。

## 当前实现

| 环节 | 当前能力 | 边界 |
|---|---|---|
| 选课前 | 修读进度、课程画像、偏好解析、最多三套方案、评分解释、权衡图 | 主要使用模拟数据 |
| 选课中 | 禁排、锁定、满员排除、备选预览与采用、撤销、换班、离线清单 | 未接入正式选课提交 |
| 选课后 | 已有轻量记录、匿名聚合和反馈回写的设计 | 尚未实现完整反馈闭环 |
| 社区评价 | jCourse 查询与评价展示接口 | 需密钥；不改变排课分数 |

## 技术结构

前端为 React、TypeScript 和 Vite，后端为 FastAPI。后端托管 frontend/dist，页面和 API 使用同一端口。backend/data/seed.json 保存示例数据。

求解器先处理时间冲突、先修、锁定和学分等约束，再以五维评分、平均效用及负荷等惩罚比较候选方案。有限宽度束搜索不能保证找到全局最优解，未找到方案也不能证明数学无解。自然语言入口默认采用规则，可选 Ollama 增强。
