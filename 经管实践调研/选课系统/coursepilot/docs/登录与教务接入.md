# 登录、教务数据与 LLM 配置交接

## 目前可以使用

首页现在先显示本地账户登录，首次使用可创建账户。登录后仍是原来的课表与右下角选课咨询。密码使用带独立盐的 scrypt 摘要；会话为后端保存的随机令牌摘要，浏览器只接收 HttpOnly、SameSite=Strict Cookie，24 小时过期，退出立即撤销。学生接口逐请求检查账户归属。

当前为课程项目本地账户，不是学校统一身份认证，不能使用学校密码。正式上线还需登录限流、找回密码、账号管理、TLS 和部署审计。

## 学校认证接口

app/auth.py 提供 SchoolIdentityProvider 协议：authorization_url 与 verify_callback。后续伙伴依据校方 OIDC/CAS 等协议实现跳转、state 校验、回调验证和身份映射，再连接本地 student_id。现在没有实际学校 SSO 服务或回调，不应将此描述为已接入学校。

LocalIdentityStore 是本地适配器，身份及会话默认存储 backend/data/auth.sqlite3。可用 COURSEPILOT_AUTH_FILE 指定路径。正式数据库伙伴可替换该适配器的 register/login/resolve/logout，保留会话撤销与归属校验；学生推荐档案仍通过 StudentRepository 存储，未改变原来的数据库接口。

正式 HTTPS 部署设置 COURSEPILOT_SECURE_COOKIE=1。本地 HTTP 保持默认。当前 API 拒绝跨来源修改请求，代理部署需核对外部 origin 和反向代理配置。

## 教务数据导入

格式参考 backend/data/seed.json。必须提供 term、major、grade、plan、requirements、courses、offerings。可选 students 字典以本地用户名映射个人教务记录：

```json
{"students":{"student01":{"completed":["FI3101"],"major":"金融学","grade":2024,"earned":{"必修":4}}}}
```

上述片段须加入完整数据集，不是单独的导入文件。没有匹配记录时使用数据集默认已修记录，仅供示例；正式数据应为所有账户提供正确映射。

在 backend 目录运行：

```powershell
python import_academic.py 学校导出.json data/imports/2026秋.json
$env:COURSEPILOT_ACADEMIC_FILE = (Resolve-Path data/imports/2026秋.json).Path
```

然后在同一终端启动系统。导入会校验课程与班次模型、重复编号、关联课程、时间和周次；目标已存在时拒绝覆盖。配置错误时启动失败，不静默退回模拟值。原 seed.json 不受影响。

app/academic.py 的 AcademicDataSource.load() 是学校教务 API 适配点。当前 JsonAcademicDataSource 从校方导出文件读取，不会抓取学校网站。若后续有官方 API，增加适配器并在 main.py 装配。当前一份课程数据对应一个专业学期；多专业和跨学期版本仍需扩展。

个人已修记录在首次创建或登录后初始化档案时同步；推荐期间不信任 LLM 修改已修记录。通用手工 /api/solve 仍接受用户自己编辑的课号，用于试排，不能当作官方毕业审核。

## 个人 LLM 预留接口

backend/.env.example 列出三个服务器环境变量：

- COURSEPILOT_LLM_BASE_URL：服务地址。
- COURSEPILOT_LLM_MODEL：模型名称。
- COURSEPILOT_LLM_TOKEN：API Token，只在后端保存。

模板不自动加载，需通过服务器环境配置；不要将真实 token 提交进代码或发给浏览器。LLMConfiguration 隐藏 token 的 repr。PersonalLLMProvider 是已装配的占位实现，现在继承本地规则，即使填入 token 也不会自动调用外部服务。后续实现 extract 并校验输出，才能启用模型。这里预留的是模型服务凭据，并非实现个人模型训练。

## 验证

python backend/check_identity.py：未登录阻断、登录、账户隔离、会话撤销、跨站阻断、Token 不出现在配置 repr。
python check_login.py：浏览器注册、登录、原课表、对话与退出；会创建随机测试账户。
python backend/check_personal_api.py：个人推荐服务行为测试（独立测试应用）。

旧的无登录浏览器测试需要先登录后运行。新账户不会自动继承旧匿名档案或浏览器记忆，避免将历史匿名数据误归属给新账户。
